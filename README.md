# Qazaq

**Язык программирования на казахском языке.** Файлы — `.qaz`. Принцип:

> Қарапайымдылық сыртында. Қуат ішінде. — *Простота снаружи. Мощность внутри.*

```qaz-run
айным есім = "Әлем".
айным x = 10.
айным y = 3.14.

жаз("Сәлем,", есім + "!").
жаз(x + y).

функ факториал(n):
    егер n <= 1:
        қайтар 1.
    қайтар n * факториал(n - 1).

жаз(факториал(10)).
```

* Точка завершает инструкцию, двоеточие открывает блок, отступ задаёт тело блока.
* Казахские буквы `ә ғ қ ң ө ұ ү һ і` — в идентификаторах, строках и комментариях.
* Собственный интерпретатор на Python (лексер → парсер → AST → интерпретатор), без `eval`/`exec`.
* Встроенные функции для данных, математики и простого машинного обучения.
* Командная строка, REPL и сайт с онлайн-редактором, работающий прямо в браузере.
* Оба написания ключевых слов: `айным`/`айнымалы`, `функ`/`функция`, `туын`/`туынды`, `интегр`/`интеграл`.

## Быстрый старт

Требуется Python 3.10+. Ядро не имеет сторонних зависимостей.

```bash
pip install -e .                 # даёт команду `qaz`
qaz run examples/01_hello.qaz
```

Без установки: `python -m qaz run examples/01_hello.qaz`.

```bash
qaz run main.qaz        # выполнить программу
qaz check main.qaz      # проверить синтаксис, не выполняя
qaz repl                # интерактивный режим (шығу — выход)
qaz version
qaz help
```

Параметры `run`: `--safe` (без файлов и графиков), `--max-steps N`, `--timeout СЕК`.

Для символьной математики и графиков: `pip install -e ".[science]"`.

Коды завершения: 0 — успех, 1 — ошибка в программе, 2 — неверное использование. Подробнее: [docs/ERRORS.md](docs/ERRORS.md).

## Сайт и Playground

Сайт `site/` — это и витрина языка, и онлайн-среда: редактор с подсветкой, автодополнением и проверкой синтаксиса
на лету, запуск кода в браузере (в фоновом потоке, с кнопкой «Остановить»), тур по языку с настоящим выводом,
каталог встроенных функций, таблица ключевых слов, русский/казахский интерфейс, светлая и тёмная темы,
настройки (⚙: режим скобок, размер шрифта, язык сообщений об ошибках), «Скопировать ссылку на код», вкладки «Токены», «Дерево» и «Шаги» (пошаговое выполнение) под редактором
и раздел **«Книга»** — объяснение, как всё устроено, на трёх уровнях (для ребёнка, подробнее, в проекте) с
словарём из 77 терминов: нажмите на подчёркнутое слово — появится пояснение.

**Код выполняется целиком в браузере** собственным JavaScript-движком Qazaq (порт интерпретатора, проверяемый
тестами на соответствие Python-версии). Сервер не нужен, код никуда не отправляется.

```bash
python scripts/build_site.py        # соберёт site/dist/index.html (одна самодостаточная страница)
node scripts/make_book_pdf.js       # (по желанию) обновит docs/QAZAQ_BOOK.pdf из раздела «Книга»
```

Откройте `site/dist/index.html` двойным кликом или разместите файл на любом статическом хостинге.
Для GitHub Pages есть готовый workflow `.github/workflows/pages.yml`.

**Серверный режим** (настоящий Python-интерпретатор, нужен для `шеш`, `туын`, `интегр`):

```bash
pip install -e ".[server,science]"
python scripts/build_site.py
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000: в панели редактора появится переключатель «Браузер (JS) / Сервер (Python)».
Запуск кода — Ctrl/⌘ + Enter. Программы на сервере исполняются в отдельном процессе с лимитами ОС.

> ⚠️ Серверный режим исполняет чужой код. Перед публичным размещением прочитайте [docs/SECURITY.md](docs/SECURITY.md).
> Браузерная версия безопасна для хостинга: код выполняется на устройстве посетителя.

## Тесты

```bash
pip install -e ".[dev,server,science]"
npm root -g   # для сквозного теста сайта нужен Playwright (npm i -g playwright); без него тест пропускается
python -m pytest
```

Тесты покрывают лексер, парсер, интерпретатор, стандартную библиотеку, Unicode (в том числе NFC/NFD),
CLI и REPL, сквозное выполнение примеров, фаззинг, бэкенд (лимиты, изоляция, параллельные запуски),
сайт в настоящем браузере и **дифференциальную проверку Python-интерпретатора и JS-движка** на сотнях программ и
тысячах случайных выражений.

## Структура

```text
qaz/          интерпретатор: lexer, parser, ast_nodes, interpreter, runtime, errors, cli, repl, runner
qaz/stdlib/   стандартная библиотека (реестр функций)
site/         сайт: JS-движок (src/engine), страница, стили, тур; сборка в site/dist
backend/      FastAPI-сервер (серверный режим Playground) и изолированный запуск
tests/        pytest
examples/     примеры программ
docs/         документация
scripts/      сборка сайта (build_site.py), справочник функций (gen_stdlib_doc.py)
```
