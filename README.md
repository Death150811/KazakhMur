# Qazaq

**Язык программирования на казахском языке.** Файлы — `.qaz`. Принцип:

> Қарапайымдылық сыртында. Қуат ішінде. — *Простота снаружи. Мощность внутри.*

```qaz-run
айным есім = "Әлем".
айным x = 10.
айным y = 3.14.

жаз("Сәлем,", есім + "!").
жаз(x + y).

функ факториал(n):
    егер n <= 1:
        қайтар 1.
    қайтар n * факториал(n - 1).

жаз(факториал(10)).
```

* Точка завершает инструкцию, двоеточие открывает блок, отступ задаёт тело блока.
* Казахские буквы `ә ғ қ ң ө ұ ү һ і` — в идентификаторах, строках и комментариях.
* Собственный интерпретатор на Python (лексер → парсер → AST → интерпретатор), без `eval`/`exec`.
* Встроенные функции для данных, математики и простого машинного обучения.
* Командная строка, REPL и онлайн-Playground.

## Быстрый старт

Требуется Python 3.10+. Ядро не имеет сторонних зависимостей.

```bash
pip install -e .                 # даёт команду `qaz`
qaz run examples/01_hello.qaz
```

Без установки: `python -m qaz run examples/01_hello.qaz`.

```bash
qaz run main.qaz        # выполнить программу
qaz check main.qaz      # проверить синтаксис, не выполняя
qaz repl                # интерактивный режим (шығу — выход)
qaz version
qaz help
```

Параметры `run`: `--safe` (без файлов и графиков), `--max-steps N`, `--timeout СЕК`.

Для символьной математики и графиков: `pip install -e ".[science]"`.

Коды завершения: 0 — успех, 1 — ошибка в программе, 2 — неверное использование. Подробнее: [docs/ERRORS.md](docs/ERRORS.md).

## Playground

Онлайн-среда: редактор Monaco с подсветкой Qazaq, запуск настоящим интерпретатором, вывод и ошибки
с позицией, 9 готовых примеров, документация, русский / казахский интерфейс, тёмная и светлая темы,
адаптивная мобильная вёрстка.

**Запуск (нужны Python 3.10+ и Node.js 18+):**

```bash
pip install -e ".[server,science]"
cd frontend && npm install && npm run build && cd ..
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Горячая клавиша запуска — **Ctrl/⌘ + Enter**.

**Режим разработки** (горячая перезагрузка фронтенда):

```bash
python -m uvicorn backend.app:app --port 8000      # бэкенд
cd frontend && npm run dev                          # фронтенд на :5173, /api проксируется на :8000
```

Подсветка и автодополнение строятся из тех же таблиц, что использует интерпретатор. После изменения
ключевых слов или встроенных функций выполните:

```bash
python scripts/gen_language_def.py      # для редактора
python scripts/gen_stdlib_doc.py        # для docs/STANDARD_LIBRARY.md
```

> ⚠️ Playground исполняет чужой код. Перед публичным размещением прочитайте [docs/SECURITY.md](docs/SECURITY.md).

## Тесты

```bash
pip install -e ".[dev,server,science]"
python -m pytest
```

Тесты покрывают лексер, парсер, интерпретатор, стандартную библиотеку, Unicode (в том числе NFC/NFD),
CLI и REPL, сквозное выполнение примеров, бэкенд (лимиты, изоляция, параллельные запуски) и
соответствие подсветки/документации реальному языку.
