### 1.3. Что работает (✔ проверено тестами и/или запуском)

**Язык и интерпретатор** (Python — `qaz/`, JavaScript — `site/src/engine/`; оба движка дают **дословно одинаковый**
результат на всём корпусе программ, это проверяет `tests/test_conformance.py`):

* Точка как завершитель инструкции; отступы; многострочные выражения без скобок; `.`/`?`/`!` как три вида концов.
* Типы: `бүтін` (целые неограниченного размера), `нақты`, `мәтін`, `логика`, `бос`, `тізім`, `кортеж`, `сөздік`,
  `жиын` (множество), `аралық` (диапазон), функции, классы.
* Условия, циклы `әзір`/`әрбір`, функции (значения по умолчанию, рекурсия, замыкания, **именованные аргументы**,
  **`*остальные` / `**именованные`**, раскрытие `*список` / `**словарь` в вызове), анонимные функции `функ(x): …`,
  классы с наследованием, исключения `байқа`/`қате`/`соңында`/`лақтыр`.
* Форматные строки `ф"…{x:.2f}…"`, срезы, цепочки сравнений, условное выражение `A егер B әйтпесе C`, конвейер `|>`,
  кортежи и распаковка, генераторы списков и словарей, математические знаки `× ÷ ≤ ≥ ≠`, комментарии `;` и `#`,
  режим «шаршы жақша» (круглые и квадратные скобки меняются местами).
* Оба написания слов: `айным`/`айнымалы`, `функ`/`функция`, `туын`/`туынды`, `интегр`/`интеграл`.
* Сообщения об ошибках: русские по умолчанию, **казахские** по выбору (`--lang kk`, переключатель на сайте).
* Стандартная библиотека: {{AUTO:builtins_count}} (см. приложение А).

**Инструменты:** `qaz run | check | repl | version | help`, флаги `--safe`, `--max-steps`, `--timeout`, `--lang`.

**Сайт** (`site/`; собирается в один HTML-файл):

* Редактор без библиотек: подсветка по правилам лексера, автодополнение, автоотступы, автозакрытие скобок,
  проверка синтаксиса на лету, подчёркивание ошибки, переход к строке ошибки.
* Запуск в браузере (JS-движок) в фоновом потоке (Web Worker) с кнопкой «Остановить»; серверный режим (настоящий
  Python) появляется, только если страницу отдаёт бэкенд.
* Вкладки под редактором: «Вывод», «Токены», «Дерево», «Шаги» (пошаговое выполнение).
* Настройки ⚙: режим скобок с преобразованием кода, язык сообщений об ошибках, размер шрифта, анимации.
* «Скопировать ссылку на код» (меню ⋯): код кодируется в адрес страницы (`#code=…`, до 6000 знаков); открыв такую ссылку, получатель видит тот же код.
* Разделы: «О языке» (6 карточек), «Тур» (9 тем), «Функции» (каталог с поиском), «Слова» (таблица ключевых слов),
  «Книга» (14 глав + словарь 77 терминов, подсказки по клику, печать в PDF).
* Русский и казахский интерфейс, светлая и тёмная темы, мобильная вёрстка.
* Доступность: axe-core WCAG 2 A/AA — 0 нарушений на всех экранах. Скорость: страница ≈ 470 КБ (≈ 125 КБ в gzip),
  первая отрисовка ≈ 0,26 с при замедлении процессора ×4.

**Бэкенд** (`backend/`): FastAPI + запуск в отдельном процессе с лимитами ОС. Нужен только для серверного режима.

### 1.5. Ждёт решения владельца

1. Разрешить создать `main` (и, возможно, Pull Request) из `claude/qazaq-lang`.
2. Включить GitHub Pages (Settings → Pages → Source: GitHub Actions).
3. Попросить носителя казахского языка проверить `docs/KAZAKH_MESSAGES_REVIEW.md` и тексты интерфейса.
4. Решить судьбу серверного режима: публиковать ли его (тогда нужен контейнер) или оставить только статический сайт.
5. Дать отзыв о сайте — «не нравится / мелко / хочу иначе» исправляется в первую очередь.
