## 16. Частые проблемы и вопросы

### 16.1. Проблемы окружения и тестов

| Симптом | Причина | Что делать |
|---|---|---|
| `playwright не найден`, тесты сайта «пропущены» | не задан `NODE_PATH` | `export NODE_PATH="$(npm root -g)"` |
| `ModuleNotFoundError: axe-core` | axe-core не установлен глобально | `npm i -g axe-core` (если сеть позволяет) или пропустить a11y (код возврата 77 = «пропущено») |
| Тест «docs/STANDARD_LIBRARY.md устарел» | меняли реестр функций | `python3 scripts/gen_stdlib_doc.py` |
| Тест «MANUAL.md устарел» | меняли главы или код, влияющий на авто-разделы | `python3 scripts/gen_manual.py` |
| Тест «нет перевода: …» | добавили сообщение об ошибке | добавить пару в `qaz/messages_kk.json` (рецепт 6) |
| Тест соответствия: «Расхождений: N» | Python и JS ведут себя по-разному | сравнить вывод двух движков на этой программе, чинить JS (эталон — Python) |
| e2e падает на «element is not visible» | меню ⚙ закрылось кликом снаружи | открыть меню (`#settingsBtn`) перед кликом по его кнопке |
| a11y: `color-contrast` | цвет текста слишком светлый/тёмный | использовать токены (`--ink-2`, `--sky-text`…); проверить обе темы |
| pytest не печатает «passed» | двойной `-q` | смотреть код возврата или запускать без `-q` |
| `git push` пишет «repository moved» | репозиторий переименован | это предупреждение; пуш проходит |
| Пуш в `main` отклонён | классификатор безопасности | не обходить; спросить владельца |
| Страница не обновилась в Artifact | не пересобрали `fragment.html` | `python3 scripts/build_site.py`, затем `Artifact publish` с тем же `url` и файлом |

### 16.2. Вопросы по устройству

**Почему оба написания слов, а не одно?** Владелец так решил: краткие слова удобны при наборе, полные — читаемы; лексер приводит их к одному виду.

**Почему сообщения об ошибках по-русски внутри?** Чтобы программа внутри `қате е:` и тесты видели один и тот же текст, а перевод был «одеждой» только при показе (глава 5.7).

**Почему `жиын` без литерала?** `{1, 2}` неотличимо от словаря на старте разбора; порядок хеша недетерминирован (глава 12, №15).

**Можно ли запускать сайт без Python?** Да: `site/dist/index.html` — один файл; Python нужен только для сборки (и серверного режима).

**Где проверить, что функция есть и в Python, и в JS?** При старте JS-движка самопроверка (`05_api.js`) падает с понятной ошибкой, если функции или методу из реестра нет реализации.

**Как узнать, какие функции вообще есть?** Приложение А или вкладка «Функции» на сайте.

**Что такое «золотая точка»?** Дизайн-мотив: золотая точка в конце заголовков повторяет точку-завершитель языка; в «Шагах» золотая полоса показывает текущую строку.

**Почему тесты ходят в Chromium без сети?** Чтобы они были быстрыми и воспроизводимыми; все внешние запросы (шрифты) намеренно обрываются.
