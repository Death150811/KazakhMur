## 9. Тесты

Правило проекта: **нельзя считать функцию готовой, пока нет теста и он не запускался**; тесты не отключаются «ради зелёного».

### 9.1. Что где проверяется

{{AUTO:tests}}

Параметризованные тесты (`@pytest.mark.parametrize`) дают больше запусков, чем функций: например, каждый блок кода документации —
отдельный запуск, а `test_star_syntax_errors` — шесть.

### 9.2. Виды проверок и зачем они

| Вид | Где | Что ловит |
|---|---|---|
| Юнит-тесты языка | `test_lexer`, `test_parser`, `test_interpreter`, `test_stdlib`, `test_unicode`, `test_sets_and_star` | поломку отдельной возможности |
| Интеграция | `test_integration`, `test_cli`, `test_backend` | сквозной путь «текст → вывод», `qaz run`, выходные коды, FastAPI, песочница |
| Документация | `test_docs` | примеры в документации перестали работать; справочник функций устарел |
| **Дифференциальный** | `test_conformance` | расхождение Python и JS на корпусе, примерах, документации, туре, книге, 4000 случайных выражений, 400 многочленов (против SymPy) |
| Фаззинг | `test_fuzz` | случайный/испорченный код роняет интерпретатор (нашёл три настоящих бага: цифра `²`, глубокая вложенность, огромные числа) |
| Казахские сообщения | `test_messages` | пропущен перевод; перекрытое правило; Python и JS переводят по-разному |
| Книга | `test_book` | битая ссылка на термин; пример не запускается; числа разошлись с проектом |
| Сайт | `test_site` → `site/test/{e2e,a11y,perf}.js` | поведение в браузере, доступность, скорость |
| Руководство | `test_manual` | это руководство устарело; в тексте упомянут несуществующий путь |

### 9.3. Как писать тесты

* Помощники из `tests/conftest.py`: `run(код, stdin="") -> вывод`, `run_err(код) -> ошибка` (проверяют текст `.message`).
* Для поведения языка предпочтительна программа в `tests/conformance_corpus.py` — она проверяет сразу **оба** движка.
* Тесты сайта запускают Chromium **без сети**; новые шаги добавляйте в `site/test/e2e.js` (нумерация в комментариях «шаг N»).
* Не используйте `sleep` без необходимости; ожидайте условия (`page.waitForFunction`). Клики по кнопкам внутри всплывающего
  меню ⚙ закрывают его при клике снаружи — открывайте меню перед нужным кликом.

### 9.4. Время и ресурсы

Полный прогон — примерно 2–4 минуты (дифференциальные тесты собирают сайт и запускают Node несколько раз). Для итераций
запускайте нужный файл: `python3 -m pytest tests/test_messages.py`. Команда фонового запуска: оборачивайте в `timeout` и не
забывайте `export NODE_PATH="$(npm root -g)"`, иначе тесты сайта будут пропущены (код возврата 77 внутри Node-скриптов).
