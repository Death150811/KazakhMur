# Часть II. Устройство проекта

## 4. Язык Qazaq: полное описание правил

Формальная грамматика — `docs/GRAMMAR.md` (EBNF), синтаксис с запускаемыми примерами — `docs/SYNTAX.md`,
функции — `docs/STANDARD_LIBRARY.md`. Эта глава — **сводка семантики** для того, кто будет менять язык: что
считается правилом, а что случайностью реализации.

### 4.1. Девять правил, которые определяют язык

1. **Инструкция заканчивается точкой.** `айным x = 10.`, `жаз(x).`. Исключение — заголовки блоков: они
   заканчиваются двоеточием (`егер x > 0:`).
2. **Правило точки** (лексер, `_operator`): `цифры.цифры` — число; `.` перед пробелом/концом строки/`#`/`;`/концом
   файла — **END**; `.` перед буквой — **DOT** (доступ к члену, `список.қос`); иначе лексическая ошибка. Из этого
   следует, что `3.14.` = число + конец, а `10.` = целое + конец.
3. **Перевод строки значим только после END или `:`** (и только если скобки закрыты). Поэтому выражение можно
   переносить без скобок и без символов продолжения: `айным s = 1 +` / `2.`.
4. **Блоки — отступами** (табуляция = 4 пробела). Блок открывается двоеточием, одна инструкция может стоять в той же
   строке (короткая форма).
5. **`айным` объявляет, `=` присваивает.** Присваивание необъявленной переменной — ошибка «Переменная не объявлена»
   с подсказкой (в том числе «вы имели в виду …»). Блоки (`егер`, циклы, `байқа`) **не создают область видимости**:
   переменная, объявленная в блоке, видна после него. Область создают только **функция** и **генератор списка**.
   Присваивание из функции внешней переменной **меняет внешнюю** (как в Python без `nonlocal`, но без `global`);
   `айным` внутри функции создаёт новую локальную.
6. **Значения — динамически типизированные.** Операции над несовместимыми типами — ошибка выполнения, которую
   можно поймать (`байқа`/`қате`). Исключение: ошибки синтаксиса и **лимиты** (`ResourceLimitError`) ловить нельзя.
7. **Правда/ложь:** ложны `жалған`, `бос`, `0`, `0.0`, `""`, пустые тізім/кортеж/сөздік/жиын/аралық; всё остальное истинно
   (строка `"0"` истинна). `және`/`немесе` возвращают **один из операндов**, а не `логика` (как в Python).
8. **Числа:** `бүтін` — любой размер (в Python — `int`, в JS — `BigInt`); `/` всегда даёт `нақты`; `//` и `%` — как
   в Python (округление к −∞, знак остатка по делителю); `**` с отрицательной степенью — `нақты`; результат
   слишком большой — ошибка «слишком велик». Сравнение `1 == 1.0` истинно; `ақиқат == 1` истинно (как в Python).
9. **Вывод `жаз(a, b, …)`** печатает значения через пробел и завершает переводом строки; текст — без кавычек,
   внутри коллекций — в кавычках (`to_repr`); `ақиқат`/`жалған`/`бос` — по-казахски; `нақты` — как `repr` Python
   (кратчайшая запись, `0.30000000000000004`, `1e+16`).

### 4.3. Типы данных и как они представлены

| Тип | Литерал | В Python-движке | В JS-движке |
|---|---|---|---|
| `бүтін` | `42`, `1_000` | `int` (не `bool`) | `BigInt` |
| `нақты` | `3.14`, `1e-3` | `float` | `number` (небольшая хитрость: целочисленное `number` в положении `нақты` отличается от `BigInt`) |
| `мәтін` | `"…"`, `'…'`, `"""…"""` | `str` | `string` (длина и индексы считаются **по символам Unicode**, а не по кодовым единицам UTF-16) |
| `логика` | `ақиқат`, `жалған` | `bool` | `boolean` |
| `бос` | `бос` | `None` | `null` |
| `тізім` | `[1, 2]` | `list` | `Array` |
| `кортеж` | `(1, 2)`, `(1,)` | `tuple` | `QTuple{items}` |
| `сөздік` | `{"а": 1}` | `dict` (ключи 1, 1.0, ақиқат — один ключ) | `QDict` (нормализует ключи так же) |
| `жиын` | только `жиын(…)` | `QSet` (обёртка над `dict`, порядок вставки) | `QSet` (обёртка над `QDict`) |
| `аралық` | `аралық(10)` | `range` | `QRange` |
| функция | `функ …`, `функ(x): …` | `QFunction`, `Builtin`, `BoundBuiltin`, `BoundMethod` | то же |
| сынып / объект | `сынып A:` | `QClass`, `QInstance` | то же |

Строки неизменяемы, срезы работают как в Python (`с[1:4]`, `с[::-1]`), индексы — с нуля, отрицательные — с конца.
Ключ словаря и элемент множества — только неизменяемые значения (не тізім/сөздік/жиын).

### 4.4. Функции

* Параметры: обычные (с необязательными значениями по умолчанию — они вычисляются **при каждом вызове** в области
  замыкания), затем `*остальные` (кортеж), затем `**именованные` (словарь). Аргументы можно передавать по имени.
* В вызове `*выражение` раскрывает коллекцию (тізім, кортеж, мәтін, жиын, аралық, ключи сөздік), `**выражение` —
  сөздік с текстовыми ключами; `*` нельзя ставить после именованных; повтор имени — ошибка.
* Анонимная функция `функ(x): выражение` — одно выражение в той же строке; её имя в трассировке `<лямбда>`.
* Замыкания захватывают окружение. Рекурсия ограничена глубиной (`Limits.max_depth`; Python — 1000 по умолчанию,
  в Playground 300; сайт — 200).
* **Встроенные функции** принимают именованные аргументы только если это явно разрешено (`kw=` — позиционные с именем:
  `сұрып(…, кері=…)`, `қосынды(…, бастау=…)`, `нөмірле(…, бастау=…)`; `kwonly=` — только по имени: `кілт=` у `сұрып`,
  `минимум`, `максимум`).

### 4.5. Классы

`сынып Имя(База):` — одиночное наследование. Конструктор — метод `жасау(өзі, …)`; `өзі` — явный первый параметр
(как `self`). Поля создаются присваиванием `өзі.x = …` (или объявлением `айным x = …` в теле класса — это поле класса).
Методы вызываются `объект.метод(…)`; поиск идёт от класса к базе. Класс без `жасау` не принимает аргументов.

### 4.6. Ошибки в программе

`лақтыр "текст".` вызывает ошибку; `байқа: … қате е: … соңында: …` ловит. Переменная `е` в обработчике —
**текст сообщения** (мәтін) на русском — перевод на казахский делается только при показе (глава 5.7).
`соңында` выполняется всегда. Ошибки, которые нельзя поймать: лексические, синтаксические, превышение лимитов.
