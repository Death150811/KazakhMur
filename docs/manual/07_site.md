## 7. Сайт

### 7.1. Как собирается

`python3 scripts/build_site.py` делает так:

1. Берёт `language_definition()` (Python-реестр) → `language.json`.
2. Склеивает `site/src/engine/[0-9]*.js` в `createQazaqEngine(LANG)` → `engine.js` (для Node-тестов; с хвостом
   `module.exports`).
3. Собирает данные `DATA = {LANGUAGE, EXAMPLES, TOUR, BOOK}`: примеры — из `examples/*.qaz` (первая строка
   `# title: …` — название), тур — `tour.json`, книга — `book.json` (с подстановкой чисел, `load_book`).
4. Подставляет в `page.html` метки: `/*__STYLE__*/` ← `style.css`, `/*__DATA__*/` ← `window.QAZ_DATA = …`,
   `/*__ENGINE__*/` ← движок, `/*__APP__*/` ← `app.js` (текст внутри `<script>` обезвреживается: `</script`, `<!--`).
5. Пишет `site/dist/fragment.html` (для Artifact: без `<html>/<head>/<body>`) и `site/dist/index.html` (полная страница с
   метаданными: описание, `theme-color`, Open Graph). Всё в `site/dist/`, **в git не хранится**.

Итог — **один самодостаточный файл**: можно открыть двойным кликом или положить на любой хостинг. Внешний запрос один —
шрифты Google Fonts (есть системные запасные; сайт работает и без них, тесты обрывают все внешние запросы).

### 7.2. Устройство `app.js` (карта)

Весь код — одна самовызывающаяся функция `(function () { … })()`; обращение к движку: `const engine =
createQazaqEngine(LANGUAGE)`. Для отладки и автотестов выставлено `window.__qazaq = { engine, run, setCode, runner, state }`.

| Раздел (по порядку в файле) | Что делает |
|---|---|
| Хранилище `store` | обёртка над `localStorage` с `try/catch` (в приватном режиме может не работать — сайт обязан работать и без него). Ключи: `qazaq.code`, `qazaq.lang`, `qazaq.theme`, `qazaq.fs` (размер шрифта), `qazaq.motion`, `qazaq.msglang` |
| Локализация `I18N`, `t()`, `pick()`, `applyI18n()` | словарь `{ru: {...}, kk: {...}}`; элементы с `data-i18n="ключ"` получают текст, `data-i18n-ph` — подсказку-плейсхолдер. Тексты тура и карточек — двуязычные поля в `tour.json` |
| Подсветка `tokenize`, `toLines`, `staticHtml`, `codeBlock` | JS-копия правил лексера для подсветки (учитывает правило точки, `;`-комментарии, f-строки). Ей же красятся примеры в книге и туре |
| Тосты и буфер обмена | `toast`, `copyText` |
| Редактор `renderEditor`, `syncScroll`, `setCode`, `insertText`, автоотступы, парные скобки, Tab/Shift+Tab, комментирование, `checkSyntax` | **прозрачный `<textarea>` лежит поверх `<pre>` с подсветкой**; номера строк — отдельная колонка (`gutter`), сдвигаемая по прокрутке. Проверка синтаксиса — `engine.check(...)` с задержкой 280 мс |
| Автодополнение `acUpdate`, `acAccept` | список из ключевых слов и функций `LANGUAGE` |
| Запуск `runner`, `run()` | Web Worker из Blob (`createQazaqEngine.toString()` вставляется в исходник воркера); запасной режим в основном потоке; «сторожевой» таймер; кнопка «Остановить» = `worker.terminate()` + новый воркер. Лимиты сайта `RUN_OPTS`: 5 с, 20 млн шагов, 200 000 символов вывода, глубина 200 |
| Серверный режим `detectServer`, `runOnServer` | если `GET /api/health` отвечает — показывается выбор «JS / Python» и `POST /api/run` |
| Вывод `errorCard`, `renderOutput`, `buildReport` | карточка ошибки (заголовок, сообщение, строка кода с `^`, ссылка «строка N», подсказка, стек, кнопка «Копировать отчёт»); перевод ошибки на выбранный язык — **в момент отображения** (`engine.translateError`) |
| Ссылка на код `shareUrl`, `codeFromHash` | код → UTF-8 → base64url → `#code=…`; при загрузке страницы такой адрес подставляет код в редактор и заменяется на `#play`; предел `SHARE_MAX = 6000` знаков |
| Настройки `setBrackets`, `applyFontSize`, `applyMotion`, `setMsgLang` | всплывающее меню ⚙. Переключатель скобок преобразует код через **токенизатор** (меняет только скобки-токены, строки и комментарии не трогает), добавляя/убирая директиву `;! жақша = шаршы` |
| Панель: примеры, меню «⋯», ввод, файл | загрузка примера, копирование, открытие файла `.qaz`, сброс, поле для `енгіз` |
| Карточки, тур, каталог, таблица слов | `renderCards`, `renderTour`, `renderLib`, `renderKeywords`; вывод карточек и тура считает **настоящий движок** при отрисовке (`inlineResult`) |
| «Лаборатория» (вкладки «Токены», «Дерево») | `engine.tokens`, `engine.tree`; клик по токену выделяет его в редакторе (`selectRange`) |
| «Шаги» `runTrace`, `showStep` | `engine.trace` строит снимок состояния перед каждой инструкцией; UI: ползунок, кнопки, автопроигрывание; золотая полоса на строке (`state.stepLine`); подсветка изменившихся переменных |
| Книга и термины `rich`, `renderBook`, `openTerm`, `route` | разметка текста `[[id|слово]]` → кнопка-термин; всплывающее окно с пояснением; роутер по хэшу: `#book`, `#book/<глава>`, остальное — главная |
| Тема и язык | `applyTheme` (атрибут `data-theme` на `<html>`), переключатель RU/ҚАЗ |
| Старт, демо-терминал | печатающийся пример в шапке: ставит точку, результат считает движок |

**Адреса (hash-роутинг):** `#play`, `#about`, `#tour`, `#library`, `#keywords` — прокрутка к разделу; `#book`,
`#book/lexer`, `#book/glossary` — режим «Книга» (атрибут `data-view="book"` на `<body>` прячет остальные разделы).

### 7.3. Дизайн-система «Steppe press»

Образ — **степь**: небесно-голубой цвет флага, золотое солнце, лента орнамента «қошқар мүйіз» (бараньи рога), жёсткие
сдвинутые тени вместо размытых. Золотая точка в конце заголовков повторяет точку-завершитель языка. Намеренно
избегали «шаблонного» вида (фиолетовые градиенты, парящие карточки), чтобы сайт не выглядел сгенерированным.

* **Токены** — CSS-переменные на `:root` в начале `style.css`: цвета страницы (`--bg --paper --ink --line …`), терминала
  (`--t-bg --t-ink …`, он тёмный в **обеих** темах), подсветки (`--c-kw --c-fn …`), акценты `--sky`, `--gold`.
  Для **текста** цвета неба используйте `--sky-text` (в светлой теме темнее — иначе контраст ниже 4,5:1 и axe-core падает).
* **Темы:** тёмная, если система не просит светлую; светлая задаётся и через `@media (prefers-color-scheme: light)`, и через
  `:root[data-theme="light"]` (три блока переменных — держите в синхронизации).
* **Шрифты:** интерфейс — Inter, заголовки — Rubik, код — JetBrains Mono (подключены с Google Fonts, есть системные
  запасные).
* **Размеры редактора:** переменные `--fs` (размер) и `--lh` (межстрочный) на `.editor` — их меняет настройка шрифта.
* **Адаптивность:** точки излома 560 / 720 / 900 / 1000 пикселей; панель редактора использует **container query**
  (`.pg { container: pg / inline-size }`): в узкой панели статус движка сворачивается в точку.
* **Печать/PDF:** блок `@media print` в конце `style.css` — только раздел «Книга», светлые цвета, разрывы страниц между
  главами, кнопки скрыты.
* **Движение:** все анимации отключаются двумя способами — системной настройкой `prefers-reduced-motion` и переключателем в ⚙
  (`data-motion="off"` на `<html>`).
* ⚠ **`overflow: clip`, а не `hidden`** у «героя» первого экрана: при `hidden` фокус на элементе у края программно
  прокручивал контейнер и сдвигал левую колонку.

### 7.4. Книга на сайте

* Источник — `site/src/book.json`: `{chapters: […], glossary: […]}`. **Редактируется вручную.**
* Глава: `id`, `title`, `lead` (одна фраза), `kid` («простыми словами»), `body` (блоки), `here` («в проекте»: где это в коде),
  `try` (`{code, caption}` — пример, исполняемый кнопкой), `check` (вопросы для самопроверки).
* Блоки `body`: `{"p": текст}`, `{"h": подзаголовок}`, `{"ul": [..]}`, `{"ol": [..]}`, `{"note": текст}`, `{"pipeline": true}`
  (схема «текст → лексер → парсер → интерпретатор → результат»).
* Разметка в тексте: `[[id|слово]]` — термин (кнопка с пояснением; `id` должен быть в `glossary`), `` `код` ``, `**жирный**`.
  Числа проекта — метки `{{N_BUILTINS}}`, `{{N_METHODS}}`, `{{N_KEYWORDS}}`, `{{W_FUNCS}}`, `{{W_METHODS}}` (подставляются
  при сборке с правильным склонением).
* Термин словаря: `{id, term, short (для ребёнка), more (точнее), chapter}`.
* Тесты: `tests/test_book.py` (все ссылки на термины существуют, примеры исполняются, числа совпадают с проектом,
  у каждой главы три уровня и ≥ 3 вопроса).
* PDF: `node scripts/make_book_pdf.js` (Playwright печатает `#book` в `docs/QAZAQ_BOOK.pdf`).
* ⚠ Текст книги — **только русский**; для казахского интерфейса подписи и кнопки переведены, главы — нет.

### 7.6. Как добавить типовые вещи на сайт

| Задача | Шаги |
|---|---|
| Новая настройка в ⚙ | кнопки в `page.html` (блок `#settingsMenu`), ключи `I18N` (ru и kk), логика рядом с `applyMotion`, сохранение через `store`, шаг в `e2e.js` |
| Новая вкладка под редактором | кнопка `.ctab` + панель `.console-body.lab` в `page.html`; ветка в `setLabPane`/`renderLab`; подписи в `I18N`; не забыть `aria-controls`/`aria-labelledby` |
| Новая тема тура | объект в `tour.json: sections` (`id`, `title{ru,kk}`, `text{ru,kk}`, `code`); тест соответствия сам прогонит код в обоих движках; e2e ожидает 9 вкладок — обновить число |
| Новый пример | файл `examples/NN_имя.qaz` (первая строка `# title: …`) + `.expected`; e2e сам прогонит все примеры |
| Глава или термин книги | правка `book.json` (см. 7.4); если ссылаетесь на термин — он должен существовать; e2e ожидает число глав (15 секций вместе со словарём) |
| Новый цвет/размер | только через переменные в начале `style.css`; проверить контраст `node site/test/a11y.js` |
