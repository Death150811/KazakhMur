## Приложение Б. Шпаргалка по языку (для тех, кто пишет программы на Qazaq)

```qaz-run
; комментарий
айным имя = "Айгүл".                 ; переменная
айным а, б = 3, 4.                   ; несколько значений
а, б = б, а.                         ; обмен
жаз(ф"{имя}: {а + б}").              ; вывод, форматная строка

функ факториал(n):                   ; функция
    егер n <= 1:
        қайтар 1.
    қайтар n * факториал(n - 1).

жаз(факториал(10)).

айным сандар = [3, 1, 2].
жаз(сұрып(сандар), [x * x әрбір x ішінде сандар]).
әрбір і, х ішінде нөмірле(сандар):   ; перебор с номерами
    жаз(і, х).

байқа:                               ; ошибки
    жаз(1 / 0).
қате е:
    жаз("Ошибка:", е).

сынып Дос:                           ; класс
    функ жасау(өзі, есім):
        өзі.есім = есім.
    функ сәлем(өзі):
        қайтар "Сәлем, " + өзі.есім.
жаз(Дос("Али").сәлем()).
```

## Приложение В. Контрольные списки

**Перед коммитом:**

- [ ] изменение сделано в **обоих** движках (если касается языка/библиотеки);
- [ ] есть тесты (юнит и/или программа в корпусе); новая программа корпуса просмотрена глазами;
- [ ] `python3 -m pytest` зелёный (с `NODE_PATH`); для сайта — e2e, a11y, perf;
- [ ] `gen_stdlib_doc.py` / `gen_manual.py` выполнены при необходимости;
- [ ] документация и `CHANGELOG.md` обновлены; нет утверждений о том, чего нет;
- [ ] сообщение коммита по-русски, с атрибуцией, как требует среда.

**Перед отчётом владельцу:** формат «Что сделано / Что теперь работает / Что проверено / Что пока не реализовано / Что дальше»; честно о непроверенном; вопросы — только про философию и
направление; ссылка на сайт; последний коммит.

**Перед публикацией сайта:** `build_site.py`; e2e + a11y + perf; `Artifact publish` на тот же `url`.
