### В. Как проверить всё самому за десять минут

1. Откройте сайт: https://claude.ai/artifact/SXdTbbowEAk2mDLHuC1hKL. Нажмите «Запустить» — внизу появится вывод. Выберите другой пример в списке «Примеры».
2. Замените код на `жаз(1 / 0).` и запустите: появится красная карточка ошибки с подсказкой. Нажмите ⚙ → «Ошибки: ҚАЗ» — карточка перепишется по-казахски без повторного запуска.
3. ⚙ → «Скобки: [ ]»: код переписывается в режим квадратных скобок и продолжает работать. Вернитесь на `( )`.
4. Под редактором откройте вкладки «Токены» (кликните по токену — он выделится в коде), «Дерево» и **«Шаги»** (нажмите «Авто» — золотая полоса пойдёт по строкам, справа меняются переменные).
5. Меню «⋯» → «Скопировать ссылку на код»: отправьте ссылку другу — он увидит ваш код.
6. Вверху нажмите «Книга»: откройте главу «Лексер», нажмите на подчёркнутое слово — появится пояснение; внизу главы — пример с кнопкой «Выполнить».
7. Нажмите «ҚАЗ»/«RU» вверху и светлую/тёмную тему — сайт перестраивается; сузьте окно до телефона — горизонтальной прокрутки нет.
8. Это руководство: https://claude.ai/artifact/2C4o7stK78o43Yyxg85MaN (или файл `docs/MANUAL.md`, или `docs/MANUAL.pdf`).
9. Для технарей: `export NODE_PATH="$(npm root -g)" && python3 -m pytest` — все тесты зелёные.
