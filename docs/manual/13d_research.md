### 13в.3. Сверка с «эталоном» (Crafting Interpreters): что покрыто

Оглавление книги — это общепринятый учебный перечень того, что есть в «настоящем» интерпретаторе. Сравнение по темам (книжные названия глав приведены по [оглавлению](https://craftinginterpreters.com/contents.html); как у нас — по коду проекта):

| Тема эталона | В Qazaq | Где |
|---|---|---|
| Сканирование (лексер) | ✅ + отступы, правило точки, Unicode | `qaz/lexer.py` |
| Представление кода (дерево) | ✅ узлы AST | `qaz/ast_nodes.py` |
| Разбор выражений и приоритеты | ✅ рекурсивный спуск | `qaz/parser.py` |
| Вычисление выражений | ✅ | `qaz/interpreter.py` |
| Инструкции и состояние (переменные) | ✅ окружения-словари | `qaz/runtime.py: Env` |
| Управление потоком (условия, циклы) | ✅ | `x_if`, `x_while`, `x_for` |
| Функции и замыкания | ✅ (+ `*`/`**`, именованные аргументы, лямбды) | `call_function` |
| **Разрешение и привязка имён (resolver)** | ⬜ **нет**: имена ищутся при выполнении по цепочке окружений | — |
| Классы и наследование | ✅ одиночное наследование | `x_classdef`, `instantiate` |
| Ошибки с позицией | ✅ строка, столбец, подсказка, трасса | `qaz/errors.py` |

Единственное «белое пятно» относительно эталона — **статический проход разрешения имён**. Последствия: (а) опечатка в имени переменной обнаруживается только когда выполнение дойдёт до этой строки (подсказка «вы имели в виду…» смягчает); (б) `qaz check` проверяет только синтаксис. Это осознанное упрощение: язык динамический, часть имён появляется во время выполнения (поля, глобальные объявления в ветках).

### 13в.4. Что стоит сделать по результатам исследования (черновой план)

Приоритет по ценности для учебного языка и по цене:

1. **История переменной в «Шагах»**: клик по имени в таблице → список «шаг N: значение» (идея «кто изменил x?», Льюис). Цена: небольшая (данные уже в трассе).
2. **Значения рядом с кодом при шагах** (идея Виктора): подпись справа от текущей строки. Цена: средняя (нужно место в редакторе).
3. **Ссылка на конкретный шаг** (как в Python Tutor): `#code=…&step=N`. Цена: малая.
4. **Статическая проверка имён в `qaz check`** (resolver по эталону): предупреждения, не ошибки. Цена: средняя; риск ложных срабатываний.
5. **Диаграмма объектов** (Python Tutor). Цена: заметная.
6. **«Уровни» для новичков** (Hedy) и **проверка столкновений слов-ключей** с обычными словами. Цена: большая, требует решения владельца о философии.
