# Стандартная библиотека Qazaq

> Файл создаётся автоматически из реестра функций (`python scripts/gen_stdlib_doc.py`). Не редактируйте его вручную.

Все функции ниже **реализованы и покрыты тестами** (`tests/test_stdlib.py`). Любое имя можно перекрыть своей переменной (`айным жаз = 5.`), но присваивание без `айным` встроенному имени запрещено.

## Core

Доступны всегда, без зависимостей.

| Вызов | Описание |
|---|---|
| `жаз(a, b, …)` | Выводит значения через пробел и переводит строку. |
| `енгіз(подсказка?)` | Читает строку из ввода. Возвращает мәтін. |
| `ұзындық(x)` | Длина мәтін, тізім, сөздік или аралық. |
| `түр(x)` | Имя типа значения (мәтін, бүтін, нақты, логика, тізім, сөздік, бос …). |
| `бүтін(x)` | Преобразует в целое число (дробную часть отбрасывает). |
| `нақты(x)` | Преобразует в число с плавающей точкой. |
| `мәтін(x)` | Преобразует значение в строку. |
| `логика(x)` | Истинность значения: 0, "", [], {} и бос — жалған. |
| `тізім(x?)` | Создаёт список из коллекции (или пустой). |
| `кортеж(x?)` | Создаёт неизменяемый кортеж из коллекции (или пустой). |
| `сөздік(пары?)` | Создаёт словарь из списка пар [[ключ, значение], …] (или пустой). |
| `аралық(конец) \| аралық(начало, конец, шаг?)` | Последовательность целых чисел; конец не включается. |
| `модуль(x)` | Абсолютное значение. |
| `минимум(коллекция) \| минимум(a, b, …)` | Наименьшее значение. |
| `максимум(коллекция) \| максимум(a, b, …)` | Наибольшее значение. |
| `қосынды(коллекция, бастау=0)` | Сумма чисел коллекции (дробные суммируются точно: 0.1 + 0.2 + 0.3 = 0.6). |
| `дөңгелекте(x, знаков=0)` | Округляет «по-школьному» (0.5 → вверх). Без знаков возвращает бүтін. |
| `еден(x)` | Округление вниз до целого. |
| `төбе(x)` | Округление вверх до целого. |
| `сұрып(коллекция, кері=жалған)` | Новый отсортированный список. Параметр кері=ақиқат — по убыванию. |
| `сүз(функция, коллекция)` | Элементы, для которых функция вернула истину. |
| `бейнеле(функция, коллекция)` | Применяет функцию к каждому элементу. |
| `кері(x)` | Копия в обратном порядке (тізім, мәтін, аралық). |

## Math

Математика и случайные числа. Без зависимостей.

| Вызов | Описание |
|---|---|
| `түбір(x)` | Квадратный корень (x ≥ 0). |
| `дәреже(основание, показатель)` | Возведение в степень (как оператор **). |
| `синус(x)` | Синус (x в радианах). |
| `косинус(x)` | Косинус (x в радианах). |
| `тангенс(x)` | Тангенс (x в радианах). |
| `логарифм(x, основание=e)` | Логарифм (по умолчанию натуральный). |
| `факториал(n)` | n! для целого 0 ≤ n ≤ 5000. |
| `комбинация(n, k)` | Число сочетаний C(n, k). |
| `кездейсоқ() \| кездейсоқ(a, b)` | Без аргументов — число [0, 1); с двумя — случайное целое от a до b включительно. |
| `таңда(коллекция)` | Случайный элемент коллекции. |
| `тұқым(n)` | Задаёт начальное число генератора случайных чисел (для повторяемости). |

## Data

Анализ данных. Без зависимостей.

| Вызов | Описание |
|---|---|
| `талда(числа)` | Статистика списка чисел: сөздік с ключами саны, қосынды, орташа, медиана, минимум, максимум, ауытқу (выборочное стандартное отклонение; 0 при одном значении). |

## AI

Простая линейная регрессия на чистом Python. Это не нейросети: scikit-learn и PyTorch пока не подключены.

| Вызов | Описание |
|---|---|
| `үйрет(x, y)` | Обучает линейную модель y = k·x + b методом наименьших квадратов. Возвращает сөздік-модель; используйте болжа(модель, x). |
| `болжа(модель, x)` | Прогноз по модели из үйрет: для числа — число, для списка — список. |

## Science

Символьная математика (SymPy) и графики (Matplotlib). Необязательные зависимости: `pip install "qazaq[science]"`.

| Вызов | Описание |
|---|---|
| `шеш(теңдеу, айнымалы?)` | Решает уравнение с одним неизвестным: шеш("x^2 - 9 = 0") → [-3, 3]. Нужен SymPy (в браузере сайта — только многочлены с целыми коэффициентами). |
| `туын(өрнек, айнымалы?)` | Производная выражения: туын("x^3") → "3*x^2". Нужен SymPy (в браузере сайта — только многочлены). Синоним: `туынды`. |
| `интегр(өрнек, айнымалы?, a?, b?)` | Неопределённый интеграл: интегр("x^2") → "x^3/3"; определённый: интегр("x^2", "x", 0, 3) → 9. Нужен SymPy (в браузере сайта — только многочлены). Синоним: `интеграл`. |
| `сыз(x, y, файл="график.png")` | Строит линейный график и сохраняет в PNG-файл. Нужен Matplotlib. Возвращает имя файла. *(недоступна в безопасном режиме)* |

## IO

Файлы. Недоступны в безопасном режиме (Playground).

| Вызов | Описание |
|---|---|
| `оқы(путь)` | Читает текстовый файл (UTF-8) целиком. *(недоступна в безопасном режиме)* |
| `сақта(путь, мәтін)` | Записывает строку в файл (UTF-8), перезаписывая его. *(недоступна в безопасном режиме)* |

## Методы встроенных типов

Вызываются через точку: `значение.метод(аргументы)`.

### мәтін (строка)

| Метод | Описание |
|---|---|
| `.жоғары(…)` | Верхний регистр. |
| `.төмен(…)` | Нижний регистр. |
| `.тазала(…)` | Убирает пробелы по краям. |
| `.бөл(разделитель?)` | Разбивает строку на список. |
| `.біріктір(список)` | Склеивает мәтін-элементы списка этой строкой. |
| `.ауыстыр(что, на_что)` | Заменяет все вхождения. |
| `.бастала(префикс)` | Начинается ли строка с префикса. |
| `.аяқтал(суффикс)` | Заканчивается ли строка суффиксом. |
| `.тап(подстрока)` | Индекс первого вхождения или -1. |
| `.сана(подстрока)` | Сколько раз подстрока встречается. |

### тізім (список)

| Метод | Описание |
|---|---|
| `.қос(x)` | Добавляет элемент в конец. |
| `.кірістір(индекс, x)` | Вставляет элемент на позицию. |
| `.шығар(индекс=-1)` | Удаляет и возвращает элемент. |
| `.өшір(x)` | Удаляет первое вхождение значения. |
| `.тап(x)` | Индекс первого вхождения или -1. |
| `.сана(x)` | Сколько раз значение встречается. |
| `.ұзарт(коллекция)` | Добавляет все элементы коллекции в конец. |
| `.көшір(…)` | Поверхностная копия списка. |
| `.босат(…)` | Удаляет все элементы. |

### сөздік (словарь)

| Метод | Описание |
|---|---|
| `.кілттер(…)` | Список ключей. |
| `.мәндер(…)` | Список значений. |
| `.жұптар(…)` | Список пар [ключ, значение]. |
| `.ал(ключ, по_умолчанию=бос)` | Значение по ключу или значение по умолчанию. |
| `.шығар(ключ, по_умолчанию?)` | Удаляет ключ и возвращает значение. |
| `.өшір(ключ)` | Удаляет ключ (ошибка, если его нет). |
| `.жаңарт(другой_сөздік)` | Добавляет пары из другого словаря. |
| `.көшір(…)` | Поверхностная копия словаря. |
| `.босат(…)` | Удаляет все пары. |

## Соглашения

- Ошибки в аргументах — это `ошибка выполнения` с точной позицией; её можно поймать через `байқа` / `қате`.
- Функции не изменяют переданные коллекции, кроме методов с глаголами-мутаторами (`.қос`, `.өшір`, `.шығар`, `.босат`, `.ұзарт`, `.кірістір`, `.жаңарт`).
- Логика/округление: `дөңгелекте` округляет «по-школьному» (0.5 → вверх, от нуля).
