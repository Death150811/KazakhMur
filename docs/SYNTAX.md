# Синтаксис Qazaq

Файлы программ имеют расширение `.qaz` и сохраняются в UTF-8. Блоки кода с пометкой `qaz` в этом
документе проверяются автоматически (`tests/test_docs.py`): они должны проходить синтаксическую
проверку, а помеченные `qaz-run` — ещё и выполняться без ошибок.

Статус: всё, что описано здесь, **реализовано и покрыто тестами**, если не указано иное.

## 1. Главное правило: инструкция заканчивается точкой

```qaz-run
айным x = 10.
айным y = 20.
жаз(x + y).
```

Точка — завершитель инструкции. Лексер различает три роли символа `.`:

| Где стоит точка | Роль | Пример |
|---|---|---|
| Между двумя цифрами | десятичная точка, часть числа | `3.14` |
| Сразу за ней пробел, конец строки, конец файла или `#` | завершитель инструкции | `жаз(x).` |
| Сразу за ней буква | доступ к полю или методу | `список.қос(1)` |

Всё остальное (например, `.5` или `x.5`) — лексическая ошибка с подсказкой.

```qaz-run
айным сан = 3.14.           # 3.14 — число, последняя точка — завершитель
айным целое = 10.           # 10 и точка-завершитель
айным а = 1. айным б = 2.   # несколько инструкций в одной строке: после точки нужен пробел
жаз(сан, целое, а + б).
```

Инструкцию можно переносить на несколько строк **без скобок**: конец инструкции определяет точка,
а не конец строки.

```qaz-run
айным сумма = 1 +
    2 +
    3.
жаз(сумма).
```

Если точка забыта, интерпретатор указывает место сразу после последнего символа инструкции:

```text
Синтаксическая ошибка: Инструкция должна заканчиваться точкой '.' (найдено ключевое слово «жаз»)
  файл main.qaz, строка 1, столбец 12
  1 | айным x = 1
    |            ^
```

## 2. Блоки: двоеточие и отступ

Заголовки блоков (`егер`, `әйтпесе`, `әзір`, `әрбір`, `функ`, `сынып`, `байқа`, `қате`, `соңында`)
заканчиваются двоеточием, а не точкой. Тело блока сдвигается вправо (пробелами; табуляция
считается как 4 пробела). **Сами заголовки блоков точкой не заканчиваются**, а инструкции внутри
блока — заканчиваются.

```qaz-run
функ тексеру(сан):
    егер сан > 0:
        жаз("Оң сан").
    әйтпесе егер сан < 0:
        жаз("Теріс сан").
    әйтпесе:
        жаз("Нөл").

тексеру(5).
тексеру(-3).
тексеру(0).
```

Короткая форма: одна инструкция в той же строке после двоеточия.

```qaz-run
егер ақиқат: жаз("бір жолда").
```

Пустой блок пишется как `өткіз.`.

## 3. Комментарии

Комментарий начинается с `#` и идёт до конца строки.

```qaz-run
# Бұл комментарий
жаз("сәлем").  # және бұл да
```

## 4. Переменные

`айным` объявляет переменную. Дальше её значение меняется обычным присваиванием.

```qaz-run
айным жас = 15.
жас = 16.
жас += 1.
жаз(жас).
```

* Присваивание необъявленной переменной — ошибка (с подсказкой «возможно, вы имели в виду …»).
* Блоки `егер`/`әзір`/`әрбір` **не создают** новую область видимости; её создаёт только функция.
* Присваивание без `айным` меняет ближайшую объявленную переменную (в том числе во внешней области).
* Встроенные имена (`жаз`, `сұрып`, …) защищены от присваивания; их можно перекрыть через `айным`.

## 5. Типы данных

| Тип | `түр(x)` | Литералы |
|---|---|---|
| Целое | `бүтін` | `42`, `1_000` |
| Дробное | `нақты` | `3.14`, `1e-3` |
| Строка | `мәтін` | `"сәлем"`, `'сәлем'`, `"""многострочная"""` |
| Логическое | `логика` | `ақиқат`, `жалған` |
| Отсутствие значения | `бос` | `бос` |
| Список | `тізім` | `[1, 2, 3]` |
| Словарь | `сөздік` | `{"а": 1, "б": 2}` |
| Диапазон | `аралық` | `аралық(10)` (лениво, без хранения чисел) |
| Функция / класс / объект | `функция`, `сынып`, имя класса | |

Строки поддерживают escape-последовательности `\n \t \r \0 \\ \" \'`. Форматные строки
записываются с префиксом `ф`; внутри `{…}` — любое выражение и необязательный формат:

```qaz-run
айным есім = "Айгүл".
айным x = 3.14159.
жаз(ф"{есім}: {x:.2f}, {1 + 1}, {{фигурные скобки}}").
```

## 6. Операторы

По убыванию приоритета:

1. вызов `f()`, индекс `a[i]`, срез `a[i:j:k]`, поле `a.b`
2. `**` (правоассоциативный): `2 ** 3 ** 2 == 512`, `-2 ** 2 == -4`
3. унарные `-` `+`
4. `*` `/` `//` `%`
5. `+` `-`
6. сравнения `== != < <= > >=`, `ішінде`, `емес ішінде` (можно цепочками: `1 < x < 10`)
7. `емес`
8. `және`
9. `немесе`

* `/` всегда возвращает `нақты`; `//` и `%` — как в Python (округление вниз).
* `және` / `немесе` вычисляются лениво и возвращают один из операндов.
* `+` склеивает строки и списки; число и строку склеить нельзя (используйте `мәтін(x)` или `ф"…"`).
* Присваивание: `=`, `+=`, `-=`, `*=`, `/=`.

## 7. Условия и циклы

```qaz-run
әрбір i ішінде аралық(1, 6):
    егер i % 2 == 0:
        жалғас.
    жаз(i).

айным n = 3.
әзір n > 0:
    жаз("кері санақ:", n).
    n -= 1.
```

* `әрбір x ішінде коллекция:` перебирает `тізім`, `мәтін` (по символам), `сөздік` (по ключам), `аралық`.
* Разложение пар: `әрбір ат, мән ішінде сөздік.жұптар():`.
* `тоқта.` выходит из ближайшего цикла, `жалғас.` переходит к следующей итерации.
  Вне цикла они запрещены (ошибка на этапе разбора).

## 8. Функции

```qaz-run
функ дәреже2(x, көрсеткіш = 2):
    қайтар x ** көрсеткіш.

жаз(дәреже2(5), дәреже2(2, 10)).

функ факториал(n):
    егер n <= 1:
        қайтар 1.
    қайтар n * факториал(n - 1).
жаз(факториал(20)).
```

* Значения параметров по умолчанию вычисляются **при каждом вызове** (изменяемое значение по умолчанию
  не «запоминается»).
* Число аргументов проверяется; ошибка называет ожидаемое и фактическое число.
* Функции — значения: их можно передавать (`сүз(жұп, список)`) и возвращать (замыкания).
* `қайтар` вне функции — ошибка разбора. Функция без `қайтар` возвращает `бос`.
* Глубина рекурсии ограничена (по умолчанию 1000 вызовов; в Playground — 300).

### Именованные аргументы

Аргументы можно передавать по имени параметра. Сначала идут обычные аргументы, затем именованные;
порядок именованных любой.

```qaz-run
функ ұшақ(қайдан, қайда = "Астана", орын = 1):
    қайтар қайдан + " → " + қайда + ", орын " + мәтін(орын).

жаз(ұшақ("Алматы")).
жаз(ұшақ("Алматы", орын = 12)).
жаз(ұшақ(орын = 3, қайдан = "Шымкент", қайда = "Орал")).
```

Ошибки понятны: неизвестное имя, значение дважды, пропущенный обязательный параметр. Методы и большинство
встроенных функций именованных аргументов не принимают; их принимают `сұрып(коллекция, кері=…)` и
`қосынды(коллекция, бастау=…)`.

### Анонимные функции

`функ(параметры): выражение` — функция без имени; тело — одно выражение в той же строке. Можно писать и
`функция(…): …`. Анонимную функцию удобно передавать в `сүз`, `бейнеле` и хранить в списках и словарях.

```qaz-run
айным квадрат = функ(x): x * x.
жаз(квадрат(7)).
жаз(бейнеле(функ(x): x + 1, [1, 2, 3])).
жаз(сүз(функ(x): x % 2 == 0, аралық(10))).
айным қос = функ(a, b = 1): a + b.
жаз(қос(2), қос(2, b = 5)).
жаз((функ(x): функ(y): x + y)(1)(2)).
```

Для многострочной функции используйте `функ имя(…):` с блоком.

Нет в версии 0.2 (запланировано): `*args`, `**kwargs`.

## 9. Списки, словари, срезы

```qaz-run
айным л = [10, 20, 30, 40].
жаз(л[0], л[-1], л[1:3], л[::-1]).
л[0] = 99.
л.қос(50).

айным д = {"қала": "Астана"}.
д["ел"] = "Қазақстан".
жаз(д, "қала" ішінде д, д.ал("жоқ", "—")).
```

Срезы работают для списка, строки и диапазона. Индекс вне диапазона и отсутствующий ключ —
понятные ошибки выполнения.

## 10. Классы

Классы небольшие и явные: поля и методы объявляются в теле, первый параметр метода — объект
(по соглашению `өзі`), конструктор называется `жасау`. Одиночное наследование.

```qaz-run
сынып Жануар:
    функ жасау(өзі, аты):
        өзі.аты = аты.
    функ дыбыс(өзі):
        қайтар "...".
    функ сөйле(өзі):
        жаз(өзі.аты + ":", өзі.дыбыс()).

сынып Мысық(Жануар):
    функ дыбыс(өзі):
        қайтар "Мияу!".

Мысық("Мурка").сөйле().
```

Метод родителя вызывается через класс: `Жануар.жасау(өзі, аты)`. В теле класса допустимы только
`функ`, `айным` (поле класса) и `өткіз.`.

## 11. Ошибки и их обработка

```qaz-run
байқа:
    жаз(10 / 0).
қате е:
    жаз("Ұсталды:", е).
соңында:
    жаз("Әрқашан орындалады").

функ тексеру(x):
    егер x < 0:
        лақтыр "теріс сан".
    қайтар x.

байқа:
    тексеру(-1).
қате:
    жаз("қате болды").
```

* `қате e:` ловит любую ошибку выполнения; `e` — текст сообщения (`мәтін`). Имя необязательно.
* `лақтыр выражение.` вызывает ошибку с текстом выражения.
* Ошибки синтаксиса и превышение лимитов (время, шаги, вывод) **поймать нельзя**.
* `соңында` выполняется всегда, в том числе при `қайтар`, `тоқта`, `жалғас`.

## 12. Unicode и казахские буквы

* Исходник читается как UTF-8; поддерживаются все буквы `ә ғ қ ң ө ұ ү һ і`.
* Идентификаторы могут содержать любые буквы и цифры Unicode (кириллица, латиница).
* Идентификаторы и ключевые слова нормализуются в форму **NFC**: слово, набранное в NFD
  (например, «й» как `и` + знак краткости), — то же слово.
* **Смесь латиницы и кириллицы в одном слове запрещена**, потому что буквы выглядят одинаково
  (латинская `i` и казахская `і`, латинская `a` и кириллическая `а`). Лексер сообщает код символа.

## 13. Два написания слов

Краткие слова удобны при наборе, полные — при чтении. Оба варианта работают одинаково и могут смешиваться
в одной программе:

| Краткое | Полное |
|---|---|
| `айным` | `айнымалы` |
| `функ` | `функция` |
| `туын(…)` | `туынды(…)` |
| `интегр(…)` | `интеграл(…)` |

```qaz-run
айнымалы а = 1.
айным б = 2.
функция қос(x):
    қайтар x + а.
функ үш(x):
    қайтар қос(x) + б.
жаз(үш(10)).
```

Полные слова `айнымалы` и `функция` — такие же зарезервированные слова, как и краткие.

## 14. Зарезервированные слова

`айным функ егер әйтпесе қайтар әзір әрбір ішінде ақиқат жалған бос сынып тоқта жалғас және немесе
емес байқа қате соңында лақтыр өткіз` и синонимы `айнымалы`, `функция`

Подробная таблица — на сайте (раздел «Ключевые слова») и в [LANGUAGE_DESIGN.md](LANGUAGE_DESIGN.md). Встроенные функции (`жаз`, `енгіз`, …) ключевыми словами
**не являются**.
