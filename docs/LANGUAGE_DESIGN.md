# Языковые решения и оценка ключевых слов

Этот документ фиксирует выбор слов и синтаксиса версии 0.1 и честно перечисляет слабые места
предварительных названий из технического задания.

## Принципы

1. **Казахский язык — основа, а не перевод Python.** Конструкции подчинены казахскому порядку и
   логике: `әрбір x ішінде тізім:` («каждый x внутри списка»), `әйтпесе егер` («иначе, если»).
2. **Простота снаружи, мощность внутри.** Ядро небольшое; сложные операции — встроенные функции
   (`талда`, `үйрет`, `шеш`, …), а не новый синтаксис.
3. **Точка — завершитель инструкции**, двоеточие — заголовок блока, отступ — тело блока.
4. **Явность вместо магии.** Нет неявных преобразований (`"а" + 1` — ошибка с подсказкой),
   необъявленная переменная — ошибка, а не молчаливое создание.

## Оценка ключевых слов

| Слово | Значение | Оценка |
|---|---|---|
| `егер` | если | ✅ естественное, общеупотребительное |
| `әйтпесе` | иначе | ✅ полное слово без обрезков; `әйтпесе егер` читается как «иначе, если» |
| `қайтар` | вернуть | ✅ повелительная форма, как `жаз`, `енгіз` |
| `жаз` | вывести / писать | ✅ короткое и естественное (функция, не ключевое слово) |
| `енгіз` | ввести | ✅ (функция) |
| `әрбір` … `ішінде` | для каждого … в | ✅ даёт читаемую фразу; `ішінде` используется и как оператор принадлежности |
| `ақиқат` / `жалған` | истина / ложь | ✅ точные термины |
| `бос` | пусто (null) | ✅ «пустой»; выбрано вместо заимствования `null` |
| `сынып` | класс | ✅ «класс, разряд» |
| `тоқта` / `жалғас` | прервать / продолжить | ✅ повелительные формы |
| `және` / `немесе` / `емес` | и / или / не | ✅ `емес` — префиксный оператор (`емес x`) и в `x емес ішінде y` |
| `байқа` / `қате` / `соңында` / `лақтыр` | попробовать / ошибка / в конце / бросить | ✅ добавлены сверх списка ТЗ для обработки ошибок |
| `өткіз` | пропустить (`pass`) | ✅ добавлено, чтобы можно было писать пустые блоки |
| `айным` / `айнымалы` | переменная | ✅ краткая форма — сокращение слова «айнымалы»; принимаются обе |
| `функ` / `функция` | функция | ✅ принимаются обе формы |
| `әзір` | цикл `while` | ⚠️ «әзір» означает «готов / пока»; для условного цикла точнее «әзірше» (пока), но слово длиннее. Оставлен по ТЗ |

Ключевые слова не могут быть идентификаторами. Встроенные функции — обычные имена, их можно
перекрыть.

## Оценка названий встроенных функций

Принцип: одно слово, естественное для казахского, без обрезков, если есть полноценное слово.

| Функция | Оценка |
|---|---|
| `жаз`, `енгіз`, `оқы`, `сақта` | ✅ глаголы-повелительные |
| `ұзындық`, `түр`, `модуль`, `қосынды`, `минимум`, `максимум` | ✅ принятые термины |
| `сұрып`, `сүз`, `бейнеле`, `кері`, `аралық` | ✅ (`аралық` — «промежуток», диапазон) |
| `талда`, `шеш`, `болжа`, `үйрет`, `сыз`, `таңда` | ✅ глаголы: «анализируй», «реши», «предскажи», «обучи», «нарисуй», «выбери» |
| `туын` / `туынды` | ✅ производная; принимаются обе формы |
| `интегр` / `интеграл` | ✅ принимаются обе формы |
| `кездейсоқ`, `факториал`, `комбинация`, `түбір`, `дәреже`, `логарифм` | ✅ термины |
| `еден` / `төбе` | округление вниз / вверх («пол» / «потолок») — образные, но запоминающиеся |
| `дөңгелекте` | ✅ «округли» |

В методах строк, списков и словарей приняты те же правила: `жоғары`/`төмен` (регистр),
`тазала`, `бөл`, `біріктір`, `ауыстыр`, `қос`, `шығар`, `өшір`, `кілттер`, `мәндер`, `жұптар`.

## Решение по сокращённым словам

Слова `айным`, `функ`, `туын`, `интегр` — сокращения. По решению основателя проекта **принимаются оба написания**:
`айным` и `айнымалы`, `функ` и `функция`, `туын` и `туынды`, `интегр` и `интеграл`. Лексер превращает синоним в
основное слово, поэтому парсер и интерпретатор о синонимах ничего не знают; для функций синоним — второе имя
той же встроенной функции (`qaz/stdlib/registry.py::alias`). Подсветка, автодополнение и справочник показывают оба
варианта. Слова `айнымалы` и `функция` зарезервированы.

## Что сознательно не вошло в 0.2

`*args`, импорт модулей, декораторы, генераторы, множества,
кортежи, асинхронность. См. [ROADMAP.md](ROADMAP.md).
