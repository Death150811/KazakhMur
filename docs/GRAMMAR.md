# Формальная грамматика Qazaq (версия 0.1)

Нотация — EBNF: `{ x }` — повторение 0 и более раз, `[ x ]` — необязательно, `|` — выбор,
`"текст"` — терминал. Грамматика соответствует `qaz/lexer.py` и `qaz/parser.py`; тесты
`tests/test_lexer.py` и `tests/test_parser.py` проверяют ключевые правила.

## 1. Лексика

Исходный текст — UTF-8; `\r\n` и `\r` приводятся к `\n`; ведущий BOM отбрасывается.

```ebnf
NAME      = letter-or-"_" , { letter | digit | "_" | combining-mark } ;   (* затем NFC *)
INT       = digit , { digit | "_" digit } ;
FLOAT     = INT , "." , INT , [ exponent ]  |  INT , exponent ;
exponent  = ( "e" | "E" ) , [ "+" | "-" ] , INT ;
STR       = '"' , { char | escape } , '"'  |  "'" , { char | escape } , "'"
          | '"""' , { char | escape } , '"""' ;
FSTR      = "ф" , STR-with-interpolation ;  (* внутри {выражение[:формат]}; {{ и }} — литералы *)
escape    = "\" , ( "n" | "t" | "r" | "0" | "\" | '"' | "'" ) ;
comment   = "#" , { any-except-newline } ;
```

Ключевые слова: `айным функ егер әйтпесе қайтар әзір әрбір ішінде ақиқат жалған бос сынып тоқта жалғас
және немесе емес байқа қате соңында лақтыр өткіз`.

Операторы и разделители: `+ - * / // % ** == != < <= > >= = += -= *= /= |> ( ) [ ] { } , :`, точка, а также
знаки-синонимы `× ÷ ≤ ≥ ≠ −` (равны `* / <= >= != -`).

Комментарий: `#` или `;` до конца строки. Директива `;! жақша = шаршы` (или `#! brackets = square`) в начале файла
меняет местами `(` ↔ `[` и `)` ↔ `]` на уровне лексера: парсер видит обычные скобки.

### Правило точки

Символ `.` разбирается так (первое подходящее правило):

1. цифры `.` цифры — часть числа `FLOAT` (десятичная точка);
2. `.` в конце текста или перед пробелом, табуляцией, переводом строки, `#` или `;` — токен **END**
   (завершитель инструкции). Так же «?» и «!» перед пробелом, концом строки или комментарием — **END**
   со значением `?` или `!` (а `!=` остаётся оператором);
3. `.` перед буквой или `_` — токен **DOT** (доступ к члену);
4. иначе — лексическая ошибка.

Из этого следует однозначность: `3.14.` — это `FLOAT(3.14) END`; `10.` — `INT(10) END`;
`а.қос(1).` — `NAME DOT NAME ( INT ) END`.

### Строки, отступы, переводы строк

* **NL** (конец логической строки) создаётся только если строка заканчивается на END или `:` и
  скобки закрыты. Если нет — перенос строки считается пробелом (продолжение инструкции).
* **INDENT / DEDENT** вычисляются только в начале логической строки (пустые строки и строки с
  одними комментариями пропускаются). Табуляция = 4 пробела. Несовпадающий уровень отступа — ошибка.
* Внутри `()`, `[]`, `{}` переводы строк игнорируются.

## 2. Синтаксис

```ebnf
program     = { NL } , { statement , { NL } } , EOF ;

statement   = compound | simple ;
block       = NL , INDENT , statement , { { NL } , statement } , { NL } , DEDENT
            | statement ;                        (* короткая форма в той же строке *)

simple      = vardecl | assign | return | break | continue | pass | raise | exprstmt ;
vardecl     = "айным" , NAME , { "," , NAME } , "=" , exprlist , END ;
assign      = target , { "," , target } , "=" , exprlist , END
            | target , ( "+=" | "-=" | "*=" | "/=" ) , expr , END ;
exprlist    = expr , { "," , expr } , [ "," ] ;   (* несколько значений без скобок — кортеж *)
target      = NAME | postfix "[" expr "]" | postfix DOT NAME ;
return      = "қайтар" , [ exprlist ] , END ;         (* только внутри функции *)
break       = "тоқта" , END ;                     (* только внутри цикла *)
continue    = "жалғас" , END ;                    (* только внутри цикла *)
pass        = "өткіз" , END ;
raise       = "лақтыр" , expr , END ;
exprstmt    = expr , END ;                      (* END может быть «.», «?» (показать значение) или «!» (утверждение) *)

compound    = if | while | for | funcdef | classdef | try ;
if          = "егер" , expr , ":" , block ,
              { "әйтпесе" , "егер" , expr , ":" , block } ,
              [ "әйтпесе" , ":" , block ] ;
while       = "әзір" , expr , ":" , block ;
for         = "әрбір" , NAME , { "," , NAME } , "ішінде" , expr , ":" , block ;
funcdef     = "функ" , NAME , "(" , [ params ] , ")" , ":" , block ;
params      = [ param , { "," , param } ] , [ [ "," ] , rest ] , [ [ "," ] , kwrest ] , [ "," ] ;   (* обычные, затем *остальные, затем **именованные *)
param       = NAME , [ "=" , expr ] ;            (* параметры без значения — перед параметрами со значением *)
rest        = "*" , NAME ;                        (* остальные обычные аргументы собираются в кортеж *)
kwrest      = "**" , NAME ;                       (* остальные именованные аргументы — в словарь; параметр последний *)
classdef    = "сынып" , NAME , [ "(" , expr , ")" ] , ":" , block ;   (* в теле: функ, айным, өткіз *)
try         = "байқа" , ":" , block ,
              [ "қате" , [ NAME ] , ":" , block ] ,
              [ "соңында" , ":" , block ] ;       (* нужен хотя бы один из қате / соңында *)
```

### Выражения (от низшего приоритета к высшему)

```ebnf
expr        = ternary ;
ternary     = pipe , [ "егер" , pipe , "әйтпесе" , ternary ] ;
pipe        = or , { "|>" , or } ;                 (* значение слева — последний аргумент справа *)
or          = and , { "немесе" , and } ;
and         = not , { "және" , not } ;
not         = "емес" , not | comparison ;
comparison  = add , { cmp-op , add } ;           (* цепочки: a < b < c *)
cmp-op      = "==" | "!=" | "<" | "<=" | ">" | ">=" | "ішінде" | "емес" "ішінде" ;
add         = mul , { ( "+" | "-" ) , mul } ;
mul         = unary , { ( "*" | "/" | "//" | "%" ) , unary } ;
unary       = ( "-" | "+" ) , unary | power ;
power       = postfix , [ "**" , unary ] ;       (* правоассоциативно *)
postfix     = primary , { call | index | DOT NAME } ;
call        = "(" , [ arg , { "," , arg } , [ "," ] ] , ")" ;
arg         = expr | "*" , expr | NAME , "=" , expr | "**" , expr ;
            (* именованные и «**» идут после обычных и «*»; имена не повторяются; «*» раскрывает коллекцию в аргументы,
               «**» — словарь с текстовыми ключами в именованные аргументы *)
index       = "[" , ( expr | slice ) , "]" ;
slice       = [ expr ] , ":" , [ expr ] , [ ":" , [ expr ] ] ;
primary     = INT | FLOAT | STR | FSTR | NAME | "ақиқат" | "жалған" | "бос"
            | "функ" , "(" , [ params ] , ")" , ":" , expr     (* анонимная функция; тело в той же строке *)
            | "(" , expr , ")"                              (* группировка *)
            | "(" , [ expr , "," , [ expr , { "," , expr } , [ "," ] ] ] , ")"   (* кортеж *)
            | "[" , [ expr , { "," , expr } , [ "," ] ] , "]"
            | "[" , expr , comp , "]"                       (* генератор списка *)
            | "{" , [ pair , { "," , pair } , [ "," ] ] , "}"
            | "{" , pair , comp , "}" ;                     (* генератор словаря *)
comp        = { "әрбір" , NAME , { "," , NAME } , "ішінде" , pipe | "егер" , pipe } ;
pair        = expr , ":" , expr ;
```

## 3. Примеры разбора

| Код | Токены (кратко) |
|---|---|
| `айным сан = 3.14.` | `KW NAME OP FLOAT END NL` |
| `жаз(x).` | `NAME ( NAME ) END NL` |
| `а.қос(1).` | `NAME DOT NAME ( INT ) END NL` |
| `егер x:` + блок | `KW NAME : NL INDENT … DEDENT` |
| `айным s = 1 +` / `2.` | `KW NAME OP INT + INT END NL` (без NL между строками) |

## 4. Семантические проверки на этапе разбора

* `қайтар` вне функции, `тоқта` / `жалғас` вне цикла — ошибка.
* Повторяющееся имя параметра; параметр без значения после параметра со значением.
* Недопустимая цель присваивания (`1 + 2 = 3.`).
* Недопустимые инструкции в теле класса; `байқа` без `қате` и `соңында`.
