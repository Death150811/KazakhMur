# Казахские сообщения: таблица для проверки носителем языка

Файл генерируется скриптом `scripts/gen_manual.py` из `qaz/messages_kk.json`. **Тексты написаны без участия носителя языка и не проверены.** Как исправлять: отредактируйте колонку «Қазақша» прямо в `qaz/messages_kk.json` (правьте только значение справа, `{имена в фигурных скобках}` оставляйте без изменений), затем выполните `python scripts/gen_manual.py` — таблица обновится, тесты проверят, что подстановки не потерялись.

Отметка проверки: ☐ — не проверено, ☑ — проверено (ставьте вручную в копии таблицы; в самом файле при следующей генерации отметки сбросятся).
