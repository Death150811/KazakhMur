# Ошибки и диагностика

Все ошибки имеют позицию (строка и столбец, считаются с 1) и, где возможно, подсказку.
Сообщения по умолчанию — на русском. Их можно показывать **на казахском** (см. раздел «Язык сообщений» ниже).

## Виды ошибок

| Вид | Класс | Когда возникает | Ловится `байқа`/`қате` |
|---|---|---|---|
| Лексическая ошибка | `LexicalError` | неизвестный символ, незакрытая строка/скобка, смесь латиницы и кириллицы, неверный отступ | нет |
| Синтаксическая ошибка | `QazaqSyntaxError` | забытая точка или двоеточие, неверная конструкция, `қайтар`/`тоқта` не на месте | нет |
| Ошибка выполнения | `QazaqRuntimeError` | деление на ноль, неопределённое имя, неверные типы, индекс вне диапазона, `лақтыр` | да |
| Превышен лимит | `ResourceLimitError` | время, число шагов, объём вывода | нет |

## Формат вывода

```text
Ошибка выполнения: Нөлге бөлу: деление на ноль
  файл main.qaz, строка 3, столбец 10
  3 | жаз(x / 0).
    |         ^
  функция тексеру() вызвана на строке 7
  Подсказка: Проверьте делитель перед делением.
```

Для рекурсии цепочка вызовов сокращается («… ещё N вызовов …»).

## Язык сообщений

Интерпретатор всегда формирует сообщение на русском — так оно одинаково видно программе внутри `байқа`/`қате`
и тестам. На казахский сообщение **переводится только в момент показа**:

| Где | Как включить |
|---|---|
| Командная строка | `qaz run файл.qaz --lang kk` (также `check` и `repl`) или переменная окружения `QAZAQ_LANG=kk` |
| Сайт | ⚙ Настройки → «Ошибки»: RU / ҚАЗ (по умолчанию — как язык интерфейса; переключение сразу перерисовывает уже показанную ошибку) |
| Серверный запуск (`qaz.runner`) | поле `"lang": "kk"` во входном JSON |

```text
Орындау қатесі: Нөлге бөлу: нөлге бөлуге болмайды
  файл main.qaz, жол 3, баған 10
  3 | жаз(x / 0).
    |         ^
  тексеру() функциясы 7-жолда шақырылды
  Кеңес: Бөлер алдында бөлгішті тексеріңіз.
```

Перевод устроен как каталог шаблонов [`qaz/messages_kk.json`](../qaz/messages_kk.json): шаблон — это русский текст
с местами для значений `{имя}`, рядом — казахский вариант. Один и тот же каталог и один и тот же алгоритм
используют Python (`qaz/messages.py`) и JS-движок сайта. Если сообщение не нашлось в каталоге, оно показывается
как есть (по-русски) — поломки не будет. Тесты (`tests/test_messages.py`) гарантируют три вещи:
каждое место в коде, где создаётся ошибка, имеет перевод; ни одно правило не «перекрыто» другим; Python и JS
переводят все программы корпуса одинаково.

> ⚠ Казахские тексты написаны без участия носителя языка и **требуют проверки**. Исправить формулировку можно
> прямо в `qaz/messages_kk.json` — править код не нужно.

## Коды завершения `qaz`

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | ошибка в программе (лексическая, синтаксическая, выполнения, лимит) |
| 2 | ошибка использования: нет файла, неизвестная команда, неверные параметры |
| 130 | прервано пользователем (Ctrl+C) |

## Частые ошибки

| Сообщение | Причина | Решение |
|---|---|---|
| `Инструкция должна заканчиваться точкой '.'` | забыта точка | поставьте `.` в конце инструкции |
| `Ожидалось двоеточие ':' после условия` | у заголовка блока нет `:` | добавьте `:` |
| `Идентификатор «…» смешивает латиницу и кириллицу` | в слове есть похожие буквы разных алфавитов | перепечатайте слово одной раскладкой |
| `Переменная «x» не объявлена` | присваивание до `айным` | `айным x = ….` |
| `Имя «x» не определено` | опечатка или переменная не создана | проверьте подсказку «возможно, вы имели в виду» |
| `Операция «+» не применима к типам мәтін и бүтін` | сложение строки и числа | `мәтін(x)` или `ф"…{x}…"` |
| `Превышена максимальная глубина вызовов` | бесконечная рекурсия | проверьте условие выхода |
| `Превышен лимит шагов исполнения` | бесконечный цикл или очень долгая программа | проверьте условие цикла |

## Ограничения (версия 0.1)

* Ошибки внутри `ф"…{выражение}…"` указывают позицию выражения внутри строки, а не весь литерал.
* Позиция ошибки выполнения — узел выражения, где она возникла (например, оператор `/` для деления на ноль).
* Живая диагностика при наборе в редакторе (без запуска) не реализована: ошибки подсвечиваются после «Запустить».
