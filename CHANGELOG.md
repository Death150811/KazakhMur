# История изменений

## 0.2.0

* **Оба написания ключевых слов:** `айным`/`айнымалы`, `функ`/`функция`, `туын`/`туынды`, `интегр`/`интеграл`.
* **Сайт** (`site/`): новый дизайн, редактор с подсветкой, автодополнением и проверкой синтаксиса на лету, запуск
  в браузере в фоновом потоке с кнопкой «Остановить», тур по языку с настоящим выводом, каталог функций,
  таблица ключевых слов, русский/казахский интерфейс, светлая и тёмная темы. Сборка — одна HTML-страница.
* **JS-движок Qazaq:** порт интерпретатора на JavaScript (целые — `BigInt`), форматирование чисел как в Python,
  математика с корректным округлением, генератор случайных чисел, совпадающий с Python по сиду.
* **Анонимные функции** `функ(x): x * 2` и **именованные аргументы** `f(a, b = 5)` в обоих движках; `сұрып(…, кері = ақиқат)`, `қосынды(…, бастау = 10)`.
* Сборка пакета проверена: колесо и sdist собираются, ставятся в чистое окружение, команда `qaz` работает. Из метаданных убрано заявление о лицензии до выбора владельцем проекта.
* **Доступность сайта:** аудит axe-core (WCAG 2 A/AA) без нарушений в светлой и тёмной темах, на десктопе и телефоне; исправлены контраст и доступ к блокам кода с клавиатуры; тест `site/test/a11y.js`.
* **Символьная математика в браузере:** `шеш`, `туын`, `интегр` без SymPy для многочленов с целыми коэффициентами, точные дроби, вывод по правилам SymPy; проверено на сотнях случайных многочленов против SymPy.
* **Дифференциальные тесты Python ↔ JS:** около 300 программ, все примеры и блоки документации, 4000 случайных выражений.
* **Исправления:** падение на цифрах не из ASCII (`5²`), переполнение стека парсера на глубоко вложенном коде,
  невозможность печати очень больших целых, рост чисел при умножении без ограничения.
* **Детерминированные вычисления:** `қосынды`, `талда`, `үйрет` не зависят от версии Python (`math.fsum`, точная дисперсия).
* Фаззинг-тесты; серверный режим Playground раздаёт новый сайт; старый React-фронтенд удалён.

## 0.1.0

Первая рабочая версия языка Qazaq.

* Ядро: лексер, парсер, AST, интерпретатор, среда исполнения (без `eval`/`exec`).
* Синтаксис: точка — завершитель инструкции; двоеточие и отступы для блоков; казахские ключевые слова.
* Типы, операторы, срезы, форматные строки, функции, замыкания, классы, исключения.
* Unicode: UTF-8, казахские буквы, нормализация NFC, защита от смеси латиницы и кириллицы.
* Стандартная библиотека: Core, Math, Data, AI (линейная регрессия), Science (SymPy, Matplotlib), IO.
* CLI (`qaz run`, `qaz check`, `qaz repl`, `qaz version`, `qaz help`).
* Playground: FastAPI + React + TypeScript + Monaco, исполнение настоящим интерпретатором в отдельном
  процессе с лимитами ОС.
* Тесты (pytest), документация на русском языке.
