# История изменений

## 0.1.0

Первая рабочая версия языка Qazaq.

* Ядро: лексер, парсер, AST, интерпретатор, среда исполнения (без `eval`/`exec`).
* Синтаксис: точка — завершитель инструкции; двоеточие и отступы для блоков; казахские ключевые слова.
* Типы, операторы, срезы, форматные строки, функции, замыкания, классы, исключения.
* Unicode: UTF-8, казахские буквы, нормализация NFC, защита от смеси латиницы и кириллицы.
* Стандартная библиотека: Core, Math, Data, AI (линейная регрессия), Science (SymPy, Matplotlib), IO.
* CLI (`qaz run`, `qaz check`, `qaz repl`, `qaz version`, `qaz help`).
* Playground: FastAPI + React + TypeScript + Monaco, исполнение настоящим интерпретатором в отдельном
  процессе с лимитами ОС.
* Тесты (pytest), документация на русском языке.
