# История изменений

## 0.2.0

* **Множества `жиын`** (порядок по добавлению, методы `қос`, `өшір`, `бірлестір`, `қиылыс`, `айырма`, `ішкіжиын`, `ішінде`, перебор, `==`) и **остальные аргументы** `*р` / `**н` в определениях функций и раскрытие `*список` / `**словарь` в вызовах — в обоих движках, с дифференциальными тестами. Сообщения об ошибках для них переведены на казахский.
* **Метрики сайта:** тест производительности `site/test/perf.js` (вес страницы 463 КБ / 122 КБ в gzip, FCP ≈ 0,26 с, LCP ≈ 0,66 с, CLS ≈ 0,001 при замедлении процессора ×4); доступность проверяется на всех видах экрана (главная, вкладки, настройки, книга, подсказка термина). Исправлено: шапка редактора переносилась на вторую строку, `overflow: clip` в «герое» (раньше фокус у края мог сдвинуть левую колонку).
* **Ещё ближе к «базису Python»:** параметр `кілт=функция` у `сұрып`, `минимум`, `максимум`; новые функции `нөмірле` (enumerate), `жұптастыр` (zip), `бірі` (any), `барлығы` (all), `символ` (chr), `код` (ord), `бөлінді` (divmod). В обоих движках, с дифференциальными тестами.
* **Раздел «Книга» на сайте** (`site/src/book.json`): 14 глав о том, как создан язык (лексер, парсер, интерпретатор, синтаксис, числа, Unicode, безопасность, тесты, сайт, дизайн, публикация, как объяснить другим). Каждая глава — три уровня: «простыми словами» (для ребёнка), «подробнее» (академически), «в проекте» (где это в коде), плюс исполняемый пример и вопросы для самопроверки. Словарь из 77 терминов; **термины в тексте — кнопки с подсказкой** (клавиатура, Esc). Печатная версия: кнопка «Сохранить как PDF» и `docs/QAZAQ_BOOK.pdf` (`node scripts/make_book_pdf.js`).
* **Вкладки «Токены», «Дерево» и «Шаги»** под редактором: показывают, как лексер и парсер разобрали код (клик по токену выделяет его в редакторе), а «Шаги» проходит программу по одной инструкции — золотая полоса на текущей строке, таблица переменных с подсветкой изменений, стек вызовов, вывод к этому шагу, ползунок и автопроигрывание.
* **Настройки сайта (⚙):** режим скобок `( )` ↔ `[ ]` с автоматическим преобразованием кода (через токенизатор, строки и комментарии не трогаются), размер шрифта, отключение анимаций, язык сообщений об ошибках.
* **Сообщения об ошибках на казахском:** общий каталог шаблонов `qaz/messages_kk.json` для Python и JS, флаг `--lang kk` / `QAZAQ_LANG=kk`, переключатель на сайте; перевод только при показе, программа внутри `байқа` видит прежний текст. Тесты полноты каталога и совпадения Python ↔ JS.
* **Оба написания ключевых слов:** `айным`/`айнымалы`, `функ`/`функция`, `туын`/`туынды`, `интегр`/`интеграл`.
* **Сайт** (`site/`): новый дизайн, редактор с подсветкой, автодополнением и проверкой синтаксиса на лету, запуск
  в браузере в фоновом потоке с кнопкой «Остановить», тур по языку с настоящим выводом, каталог функций,
  таблица ключевых слов, русский/казахский интерфейс, светлая и тёмная темы. Сборка — одна HTML-страница.
* **JS-движок Qazaq:** порт интерпретатора на JavaScript (целые — `BigInt`), форматирование чисел как в Python,
  математика с корректным округлением, генератор случайных чисел, совпадающий с Python по сиду.
* **Фирменные особенности языка:** комментарий `;`; «предложения» `.` `?` `!`; знаки `× ÷ ≤ ≥ ≠`; конвейер `|>`; условное выражение `A егер B әйтпесе C`; режим «шаршы жақша» (`;! жақша = шаршы`).
* **Базис, как у Python:** кортежи (`кортеж`), распаковка и обмен `а, б = б, а.`, генераторы списков и словарей `[x * x әрбір x ішінде …]`.
* **Анонимные функции** `функ(x): x * 2` и **именованные аргументы** `f(a, b = 5)` в обоих движках; `сұрып(…, кері = ақиқат)`, `қосынды(…, бастау = 10)`.
* Сборка пакета проверена: колесо и sdist собираются, ставятся в чистое окружение, команда `qaz` работает. Из метаданных убрано заявление о лицензии до выбора владельцем проекта.
* **Доступность сайта:** аудит axe-core (WCAG 2 A/AA) без нарушений в светлой и тёмной темах, на десктопе и телефоне; исправлены контраст и доступ к блокам кода с клавиатуры; тест `site/test/a11y.js`.
* **Символьная математика в браузере:** `шеш`, `туын`, `интегр` без SymPy для многочленов с целыми коэффициентами, точные дроби, вывод по правилам SymPy; проверено на сотнях случайных многочленов против SymPy.
* **Дифференциальные тесты Python ↔ JS:** около 300 программ, все примеры и блоки документации, 4000 случайных выражений.
* **Исправления:** падение на цифрах не из ASCII (`5²`), переполнение стека парсера на глубоко вложенном коде,
  невозможность печати очень больших целых, рост чисел при умножении без ограничения.
* **Детерминированные вычисления:** `қосынды`, `талда`, `үйрет` не зависят от версии Python (`math.fsum`, точная дисперсия).
* Фаззинг-тесты; серверный режим Playground раздаёт новый сайт; старый React-фронтенд удалён.

## 0.1.0

Первая рабочая версия языка Qazaq.

* Ядро: лексер, парсер, AST, интерпретатор, среда исполнения (без `eval`/`exec`).
* Синтаксис: точка — завершитель инструкции; двоеточие и отступы для блоков; казахские ключевые слова.
* Типы, операторы, срезы, форматные строки, функции, замыкания, классы, исключения.
* Unicode: UTF-8, казахские буквы, нормализация NFC, защита от смеси латиницы и кириллицы.
* Стандартная библиотека: Core, Math, Data, AI (линейная регрессия), Science (SymPy, Matplotlib), IO.
* CLI (`qaz run`, `qaz check`, `qaz repl`, `qaz version`, `qaz help`).
* Playground: FastAPI + React + TypeScript + Monaco, исполнение настоящим интерпретатором в отдельном
  процессе с лимитами ОС.
* Тесты (pytest), документация на русском языке.
